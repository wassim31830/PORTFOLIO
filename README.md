# Portfolio - Zabar Wassim

Un portfolio moderne et responsive créé avec HTML5, CSS3 et JavaScript vanilla, basé sur le contenu complet du PDF portfolio.

## 🚀 Fonctionnalités

- **Design moderne** : Interface épurée avec des animations fluides
- **Responsive** : Optimisé pour tous les appareils (mobile, tablette, desktop)
- **Navigation fluide** : Menu hamburger pour mobile, navigation sticky
- **Animations** : Effets de parallaxe, animations au scroll, barres de compétences animées
- **Performance** : Code optimisé, chargement rapide
- **Accessibilité** : Navigation au clavier, contraste optimisé
